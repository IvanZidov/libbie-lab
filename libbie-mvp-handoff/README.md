# Demo data and assets

This directory contains the supplied fictional scenarios, inventory, benchmark data, and branding assets used by Libbie Lab.

| Directory | Contents |
| --- | --- |
| `fixtures/` | 12 synthetic development scenarios and 14 fictional listing records |
| `reference/` | Supplied benchmark CSV and recomputed agreement summary |
| `branding/` | TextValue assets and font licenses |

Synthetic scenarios are development evidence and require human review before they can support a release decision. See the [evaluation policy](../docs/evaluation-policy.md).
