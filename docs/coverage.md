# Coverage and limits

| Capability      | Delivered                                                                                                                                                                         | Limits                                                                                                                                                               |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Foundation         | Six responsive screens, supplied colors/fonts/scribble, preserved OFL, SQLite migration, idempotent 12-scenario/14-property seed                                                  | One local workspace, no deployment                                                                                                                                   |
| Conversation state | Immutable append IDs, exact revisions, source quotes, four-field export, richer requirements, corrections/conflicts, historical snapshots                                         | Bounded English rule extractor, not a live general-language classifier; approximate move-date rule uses fictional 2026 context                                       |
| Search             | Explicit request/approval, accepted vs proposed vs rejected areas, annual conversion, no filter widening, canonical IDs, verified vs conditional options, stored trace            | Style ranking recognizes warm/homely and bright/open words; unfamiliar meanings remain limited. No routing or vector retrieval                                       |
| Simulation         | New runs, manual composer, explicit triggers, bounded 4-turn automated policy, start/pause/resume, virtual clock, persisted jobs, optional live client                            | Generated variations are manual/scripted proposals, not LLM-generated blueprints. No interactive paired evaluation mode                                              |
| Coaching/nurture   | Evidence-based next actions, editable drafts, stop and requested-contact-date suppression, due follow-up opportunities                                                            | No employee score, client sentiment score or autonomous outreach                                                                                                     |
| Enrichment         | Canonical record, description traits, broker updates, property-version history, superseded attributes, illustration labeled as concept                                            | No external verification or location provider. Trait vocabulary is intentionally small                                                                               |
| Review/evaluation  | Blind UI, normal four-field form, evidence, separate annotations, ambiguous/adjudication states, frozen paired replay, actual field/case counts, failed checks, legacy CSV scorer | One local reviewer, no independent adjudication/reliability statistics. No teacher/judge calls. No production population inference or statistical significance claim |
| Improvement        | Feedback/development cases, three immutable strategy configurations, exact-source report checks, explicit gated promotion and rollback                                            | v2 adds ambiguity warning; v3 fixes the optional S13 negated-selling failure. No measured live-model-quality improvement, automatic prompt rewrite or fine-tuning    |

The baseline and candidate both pass the 12 synthetic opening checks. v2 adds a landlord-stage ambiguity warning and does not improve four-field agreement. All supplied references remain unreviewed unless a real operator annotates them. Scripted pass counts are implementation evidence only.

## Verification performed

`npm test` covers source preservation, speaker attribution, seller/landlord direction, offers/ranges/monthly arithmetic, chat continuity, correction precedence, rejected locations, unknown pets, injected/fake listing ID protection, no-match behavior, contact-date and stop suppression, durable family flow, idempotency, revision conflicts, workspace exclusion, data retention in a second Node process, paired reports, blocked and eligible promotion, rollback, bounded job pause/resume, provider usage capture, malformed output and timeout failure.

Tests use isolated temporary databases and an explicitly automated test reviewer. The real demo database has no fabricated human annotations. Production build/type checking also passes.

Browser checks verified the actual UI and initial family search, including approval gating and conditional SYN-P001. Responsive checks cover desktop and a narrow mobile viewport. Browser testing is a smoke test, not a full accessibility audit.

See the [case-study coverage](case-study-coverage.md) and [client walkthrough](DEMO-TUTORIAL.md). The optional S13 and v3 now demonstrate a measured development-case improvement. Every included case must be reviewed before promotion.
